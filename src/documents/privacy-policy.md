This Privacy Policy governs the manner in which Benny Nguyen, the author of Discord Status as Image (referred to as "we", "our", or "us") collects, uses, maintains, and discloses information collected from users (referred to as "you" or "user") of Discord Status as Image.

### 1\. Information Collection and Usage

**1.1 Discord Information:**

When you use Discord Status as Image, [Refiner Discord Bot](https://github.com/pdt1806/refiner-discord-bot) fetches certain information from your Discord account, including User ID, Username, Display name, Avatar, Status, Created date, Banner image (if applicable), Accent color (if applicable), Current activity (if applicable), Current status (a.k.a mood, if applicable), Badges (if applicable), Avatar decoration (if applicable), and Server tag (if applicable). This information is only retrieved for users in the Discord server, and by joining the Discord server through the provided invite link, you consent to the collection of this data. Your account details are visible to other users in the server on Discord, but none of this data is stored in the product's database.

**1.2 Custom Banner Image:**

If you choose to upload a custom banner image, you acknowledge and agree that this image will be stored in our database. The uploaded image is visible and accessible by the public through Discord Status as Image, or by direct request to the database. The unique identifier for each uploaded banner image is a 15-character long ID. This ID is assigned and displayed to users when creating the "large card" with the uploaded banner image for the first time. We recommend users store this ID somewhere safe for later use.

We are not responsible for any issues or consequences arising from the use or visibility of the uploaded image. If you wish to request the removal of a banner image, please send an email to [me@bennynguyen.dev](mailto:me@bennynguyen.dev). The email must contain the ID of the banner to be removed.

### 2\. Data Security

We prioritize the security of your data. While Discord information is fetched temporarily and not stored, custom banner images are securely stored in our database. We implement security measures to protect against unauthorized access, alteration, disclosure, or destruction of your personal information.
